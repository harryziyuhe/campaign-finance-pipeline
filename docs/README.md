# Documentation Index

| Document | Purpose |

| [`firm-pac-donor-profile-pipeline.md`](firm-pac-donor-profile-pipeline.md) | Focused workflow notes for the staged individual firm-PAC donor profile pipeline. |

The migration log is the first place to check if an older script or notebook breaks after the reorganization.
